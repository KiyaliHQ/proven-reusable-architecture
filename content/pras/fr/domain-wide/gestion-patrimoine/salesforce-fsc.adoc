== Resume

Solution CRM basee sur *Salesforce Financial Services Cloud*, deployee pour le secteur Gestion de Patrimoine de la BNC.

== Contexte

*Secteur* : Gestion de Patrimoine +
*Statut* : *EN PROMOTION* vers Transversal +
*Proven-in-use* : 18 mois en production +
*Adoption* : 100% des conseillers (50+ utilisateurs)

== Solution

=== Architecture

==== Composants

[plantuml]
----

* *Platform* : Salesforce Financial Services Cloud

* *Holdings* en temps reel

* *Suitability checks*
* *Audit trail* complet

=== Integrations

==== Core Banking System

----
