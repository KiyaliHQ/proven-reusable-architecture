= Architectural Overview — PRA Registry
:page-title: Architectural Overview
:keywords: architecture, overview, platform, ci-cd, governance
:pra-hide-meta: true

The PRA Registry (Proven Reusable Architecture) is Banque Nationale's centralized platform for cataloguing, sharing and governing architectural patterns validated in production.

This document presents the complete platform architecture, its flows, AI agents and governance.

== 1. Platform Overview

The registry follows a *Git-centric* model: the GitHub repository is the single source of truth. Two publication targets are automatically fed on every merge.

[plantuml]
----
@startuml
skinparam backgroundColor transparent
skinparam defaultFontName "Segoe UI"
skinparam defaultFontSize 13
skinparam shadowing false
skinparam roundCorner 10
skinparam ArrowColor #333333

actor "Architects\n(~200)" as arch

package "GitHub Repository" as repo #c8102e {
}

rectangle "GitHub Actions\n(Automated CI/CD)" as ci #333333

rectangle "GitHub Pages\n(Filterable dashboard)" as ghp #2563eb
rectangle "Confluence\n(Enterprise wiki)" as conf #2563eb

arch -down-> repo : Contribute\n(Pull Request)
repo -down-> ci : Merge to main
ci -right-> ghp : Build\nAsciidoctor + PlantUML
ci -left-> conf : Publish\nDocker Publisher
arch -right-> ghp : Browse
arch -left-> conf : Browse

note bottom of repo
  Single source of truth
  PRAs · Guides · Templates
  Config · AI Agents
end note
@enduml
----

*Key principle*: Git is the only write point. GitHub Pages and Confluence are read-only views, regenerated on every merge.

*Important*: Status (`operationalizing`, `operationalized`, `deprecated`) is PRA metadata, not a hierarchy element.

== 4. AI Agents — Architecture

Two AI agents allow architects to interact with the registry in natural language, directly from VS Code or Claude Code. Both are *config-driven* and *structure-agnostic*.

[plantuml]
----
@startuml
skinparam backgroundColor transparent
skinparam defaultFontName "Segoe UI"
skinparam defaultFontSize 12
skinparam shadowing false
skinparam ArrowColor #333333
skinparam sequence {
  ParticipantBackgroundColor #ffffff
  ParticipantBorderColor #d1d5db
  LifeLineBackgroundColor #f9fafb
}

actor "Architect" as arch
participant "PRA Explorer" as explorer #c8102e
participant "PRA Guide" as guide #2563eb
database "Registry\n(config + content)" as reg

== Find a pattern ==

arch -> explorer : "I need to integrate\nSalesforce for Corporate"
explorer -> reg : Read config + scan PRAs
explorer --> arch : "Salesforce FSC available\n2 proven-in-use, score 8/10"

== Understand the process ==

arch -> guide : "How do I submit a PRA?"
guide -> reg : Read guides + docs
guide --> arch : "1. Copy template\n2. Document FR+EN\n3. Submit PR"

@enduml
----

  GitHub automatically assigns
  reviewers based on file paths

== 7. CI/CD Pipeline

On every merge to `main`, two parallel jobs publish content in under 5 minutes.

[plantuml]
----
@startuml
skinparam backgroundColor transparent
skinparam defaultFontName "Segoe UI"
skinparam defaultFontSize 12
skinparam shadowing false
skinparam ArrowColor #333333
skinparam sequence {
  ParticipantBackgroundColor #ffffff
  ParticipantBorderColor #d1d5db
}

actor "Architect" as arch
participant "GitHub" as gh #333333
participant "GitHub Actions" as ci #c8102e
participant "GitHub Pages" as ghp #2563eb
participant "Confluence" as conf #2563eb

arch -> gh : Merge PR to main
gh -> ci : Trigger CI/CD

ci -> ghp : Job 1: Asciidoctor\n+ PlantUML -> HTML
ci -> conf : Job 2: Docker\nPublisher -> Pages

ghp --> arch : Site updated (< 2 min)
conf --> arch : Pages updated (< 3 min)

note over ci
  Two parallel jobs
  Zero manual intervention
end note
@enduml
----

*Result*: A single merge to `main` updates both platforms simultaneously. Zero manual intervention.
